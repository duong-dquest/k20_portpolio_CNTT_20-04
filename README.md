## 7. Hướng dẫn kiểm tra chức năng

Kiểm tra lần lượt năm liên kết điều hướng, ba thẻ sở thích, hai dự án, lộ trình và biểu mẫu. Với biểu mẫu, nhập họ tên từ 2 ký tự, email hợp lệ và nội dung từ 10 đến 500 ký tự; nút gửi phải mở `ket-qua.html`.

## 8. Hướng dẫn triển khai GitHub Pages

1. Tạo repository GitHub mới.
2. Đưa toàn bộ nội dung thư mục dự án lên repository.
3. Vào **Settings → Pages**.
4. Chọn **Deploy from a branch**, chọn nhánh xuất bản (thường là `main`) và thư mục `/ (root)`.
5. Lưu cấu hình, chờ GitHub Pages triển khai rồi mở URL được GitHub cung cấp.
6. Kiểm tra lại CSS, ảnh, liên kết và form trên URL đã triển khai.
